# Заготовка

Приложение для меню на неделю: план, замена блюд, список покупок, режим готовки.
Открыть: https://<логин>.github.io/<репозиторий>/

## Общий план на двух телефонах

Если общее хранилище уже подключено, на первом телефоне откройте «Неделя → Наш кабинет» и дождитесь времени синхронизации. Нажмите «Позвать Дашу» или «Позвать Максима», откройте ссылку на втором телефоне и подтвердите подключение. Ссылка даёт доступ к общему плану, отправляйте её только второму участнику.

Для нового хранилища создайте Google Таблицу, откройте «Расширения → Apps Script» и вставьте содержимое `Code.gs`. Запустите `setupHousehold` и предоставьте доступ к этой таблице. В настройках проекта откройте свойства скрипта и скопируйте значение `HOUSEHOLD_CODE`. Разверните скрипт как веб-приложение с выполнением от своего имени и доступом «У всех». Адрес с окончанием `/exec` и код внесите в «Наш кабинет» на телефоне, с которого хотите перенести исходное меню.
