# Заготовка

Приложение для меню на неделю: план, замена блюд, список покупок, режим готовки.
Открыть: https://dryaginmax74reg-lgtm.github.io/zagotovka/

## Одна ссылка для тестовых семей

1. Организатор создаёт одну Google Таблицу. В ней открывает «Расширения → Apps Script» и вставляет `Code.gs`.
2. В редакторе выбирает и один раз запускает `setupHousehold`. Предоставляет доступ к таблице.
3. Выбирает «Развернуть → Новое развёртывание → Веб-приложение». Запуск от своего имени, доступ «Все», включая пользователей, которые не вошли в Google. Если скрипт уже развёрнут, нужно опубликовать новую версию развёртывания.
4. Запускает `showBetaLink`, открывает «Журнал выполнения» и копирует ссылку на «Заготовку». Эту ссылку отправляет тестировщикам. Код старого семейного плана им не нужен.

Тестировщик выбирает «Готовлю один» или «Готовим вместе». В одиночном режиме данные остаются в браузере. Пара создаёт общий план и отправляет приглашение через «Наш кабинет». Планы тестовых семей хранятся в отдельных листах одной таблицы. На одно развёртывание предусмотрено до 25 семей. Таблица остаётся закрытой, доступ к плану даёт только ссылка-приглашение.

## Общий план на двух телефонах

Если общее хранилище уже подключено, на первом телефоне откройте «Неделя → Наш кабинет» и дождитесь времени синхронизации. Нажмите «Пригласить на второй телефон», откройте ссылку на втором телефоне и подтвердите подключение. Ссылка даёт доступ к общему плану, отправляйте её только второму участнику.

Для нового хранилища создайте Google Таблицу, откройте «Расширения → Apps Script» и вставьте содержимое `Code.gs`. Запустите `setupHousehold` и предоставьте доступ к этой таблице. В настройках проекта откройте свойства скрипта и скопируйте значение `HOUSEHOLD_CODE`. Разверните скрипт как веб-приложение с выполнением от своего имени и доступом «У всех». Адрес с окончанием `/exec` и код внесите в «Наш кабинет» на телефоне, с которого хотите перенести исходное меню.
